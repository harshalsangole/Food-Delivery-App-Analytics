# Food Delivery Business Analytics Dashboard

## Project Overview
This project analyzes a real-world food delivery dataset to extract actionable business insights regarding customer retention, delivery efficiency, and restaurant performance. The interactive Power BI dashboard provides an industry-level view of key metrics for stakeholders.

## Tech Stack
* **Tool:** Power BI
* **Data Transformation:** Power Query
* **Data Modeling:** Star Schema (Orders, Customers, Restaurants, Date)
* **Calculations:** DAX (Data Analysis Expressions)

## Key Business Insights & Outcomes
* **Operational Efficiency:** Tracked late deliveries and overall cancellation percentages to identify supply-chain bottlenecks.
* **Customer Retention:** Evaluated repeat customer behavior and average orders per customer to gauge platform loyalty.
* **Financial Performance:** Monitored Total Revenue, Average Order Value (AOV), and Month-over-Month growth trends.
* **Restaurant Segmentation:** Categorized restaurant partners by Cost (Budget, Mid Range, Premium) and Rating (Excellent, Good, Average, Low) to optimize platform offerings.
